## 🧠 Learning Approach

Each topic will follow a practical learning process:

1. **Understand:** Learn the underlying concept and why it matters.
2. **Connect:** Relate it to real-world applications.
3. **Implement:** Write code or complete a practical exercise.
4. **Evaluate:** Test results and understand limitations.
5. **Document:** Record explanations, implementation details, and outputs.
6. **Review:** Practice interview questions and explain concepts in my own words.

The emphasis is on understanding how things work rather than simply using libraries or copying implementations.
